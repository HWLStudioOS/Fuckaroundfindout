# Routines

Sleep, diet, recovery operating rules. Default templates for the morning-brief agent.

## Sleep target

- Wake: 5:00 (aspiration), 6:30 (current realistic baseline).
- Sleep: 21:00-22:00 (aspiration), 23:00 (current realistic baseline).
- Phone in another room.
- Last activity before sleep: not social media (current pattern, to break).

## Morning sequence (default)

1. 06:00-06:30 wake.
2. Water + salt + creatine.
3. 10-15 min outside walk (codex keystone habit).
4. Strength A on Monday AM, Strength B on Thursday AM, before email or client work.
5. Deep work block 09:30-11:00. Phone grayscale, in another room, DND.

## Default meals

- Breakfast: eggs + wraps OR yogurt bowls + berries + granola.
- Lunch: mince + rice + beans OR rice + cooked veg + lean protein.
- Dinner: similar to lunch, low-fibre options on Friday/Saturday if Sunday is a long run.
- Pre-long-run Saturday evening: 120g carbs at dinner (white rice, lean protein, honey/banana).

## Long run fueling

See `health/fuel.md` for the validated 51g/hr protocol. Maya 1:00 handoff template.

## Recovery rules (HRV)

Rolling 7-day average, never single-day.
- Within 5ms of baseline: run planned session.
- Down 6-10ms with no context: easy, replace quality with Z2.
- Down 11+ms for 2+ days: skip next quality, easy only, reassess.
- Crashed but obvious context (alcohol, illness, work stress): note context, ignore the number, run planned session unless subjective feel is also off.

## Knee status traffic light

- Green: full plan.
- Yellow: swap hardest session for cross-train, hold long run.
- Red: 72h no running, physio call, walking only.

Knee override beats HRV override in both directions.

## Strength adherence rule

Two sessions per week, 35 minutes each, Mon AM + Thu AM. Ring-fenced like client meetings. If missed, no Saturday catch-up. If 0 of 2 in a week, the system fails the strength dimension.

## Race week (6-11 July)

Dailies relax to outside-only. Deep work + writing optional. Recovery + race prep are the only things that matter.
