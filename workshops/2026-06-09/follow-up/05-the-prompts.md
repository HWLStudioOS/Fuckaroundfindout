# The Prompts

Everything I ran on the night, cleaned up so it works for your system, not mine.

These assume your four files exist (doc 02 builds them). The prompts are short on purpose. The files are doing the heavy lifting. That was the whole point of the demo: the prompt wasn't clever, the context was.

## 1. The cascade prompt (the live demo)

This is the one you watched turn one idea into five drafts.

If you're in Claude Code or Codex, paste as-is. If you're in a Claude or ChatGPT Project, delete the "Read these files first" block, the project already knows them.

```
Read these files first:

- content/strategy.md
- content/voice-dna.md
- content/publishing-rules.md
- content/waterfall.md

Then run this idea through my waterfall:

[YOUR IDEA HERE. Three to six sentences. A real observation from your work, with the tension stated plainly. Mine on the night: the funnel is dead, people now find you from any angle, so you don't build a funnel, you build a world.]

Create five outputs:

1. A newsletter or Substack essay draft, 700 to 900 words.
2. A cinematic essay script, 60 to 120 seconds.
3. A talking-head reel script, 45 to 75 seconds.
4. A LinkedIn editorial post.
5. An X thread, 5 to 7 tweets, the spine of the essay.

Rules:

- Drafts, not finished posts.
- Obey my publishing rules.
- Keep my voice. If a line could be anyone's, cut it.
- Short sentences.
- Give me the strongest line from each output at the end.
- End by flagging anything that brushed a publishing rule.
```

## 2. The idea-capture prompt

For when something happens on a job and you want it in the inbox before it evaporates.

```
Add this to ideas/inbox.md with today's date. Don't develop it, just capture it cleanly:

[what happened, in your own words, however rough]
```

In a chat app, keep a phone note instead and paste it in fortnightly.

## 3. The fortnight-review prompt

Run this every two weeks. It picks your next idea.

```
Read ideas/inbox.md, content/strategy.md and content/publishing-rules.md.

Score each captured idea against my strategy. Which one is worth more than a tweet? Recommend one as the idea of the fortnight and tell me why in three sentences. Flag any that break my publishing rules.
```

## 4. The editing pass

The drafts are the start, not the end. This is where you come back in. After the cascade runs:

```
For each draft, mark which lines are genuinely mine and which are filler. Be harsh. Then give me a cut-down version of each, keeping only the lines that earn their place.
```

You still make the final call. Keep the useful lines, cut the generic ones, sharpen the first line, ship.

## 5. The habit that improves everything

Before running any big prompt, ask the AI to improve it first:

```
Here's a prompt I'm about to run. Make it better. Tighter instructions, clearer output format, then show me the improved version.
```

I do this constantly, usually by dictating a rough version out loud and letting the AI tidy it. The AI is better at writing prompts for itself than you are. Let it.
