Three Looms, under 6 minutes each. Operator posture, screen share, no slides, no intro music. "Don't expect a whole course" was the promise, so keep them rough and real. Record in one take each, mistakes left in.

Safety first, same as the live demo: clean workshop folder only, private folders closed, Superhuman/Slack/WhatsApp/banking closed, notifications off.

## Loom 1. Install Claude Code (and where Codex fits), ~5 min

1. Cold open on a browser. "This is the only fiddly bit. Ten minutes, once."
2. Open Terminal via Spotlight. Say out loud: it's just a text box for your computer.
3. Paste the install command from doc 01, run it, let it do its thing.
4. Make an empty folder on the desktop, `my-content-engine`. cd into it by dragging the folder onto the terminal.
5. Type `claude`, do the browser sign-in, mention it needs a paid plan (Pro or above).
6. Say one sentence: "Codex is OpenAI's version, same idea, doc 01 has the command. Pick one, don't run both."
7. Close: "That's the install done forever. Next video builds your system."

## Loom 2. The interview prompt and the folder, ~6 min

1. Open in the empty folder with `claude` running.
2. Paste the interview prompt from doc 02. Answer the first two or three questions on camera, honestly, dictating if you want to show Wispr Flow.
3. Jump-cut past the middle of the interview ("this took me 25 minutes, do not rush it").
4. Show the moment it writes the four files. Open the folder in Finder so they see real files appear.
5. Open one file in Obsidian, read two lines of the voice file out loud, point at a phrase that's genuinely yours.
6. Close: "The AI is not the system. This folder is. Last video runs the engine."

## Loom 3. The cascade, ~5 min

1. Open on the folder with the four files in place.
2. Paste the cascade prompt from doc 05 with a fresh idea, not the workshop one, so they see it's repeatable.

4. When it lands, do a 60-second honest edit on one output. Keep a line, kill a line, sharpen the opener.
5. Close: "Strong first draft in minutes instead of a blank page in hours. That's the entire pitch. Questions in the Slack."
