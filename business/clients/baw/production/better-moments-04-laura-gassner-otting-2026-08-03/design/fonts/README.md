# Bundled type

These files reproduce the locked Better at Work type roles without installing fonts on the host Mac.

Downloaded from the official `google/fonts` repository on 3 August 2026:

- `Newsreader[opsz,wght].ttf` from `ofl/newsreader/`.
- `Newsreader-Italic[opsz,wght].ttf` from `ofl/newsreader/`.
- `Manrope[wght].ttf` from `ofl/manrope/`.
- `IBMPlexMono-Medium.ttf` from `ofl/ibmplexmono/`.

The matching SIL Open Font Licence text is retained beside each family. The generator embeds these files into the editable SVG sources, then renders the PNG set through local headless Chrome.
