# Year One Workshop, Final Run Of Show

**Title:** How to Use AI to Run Your Content So You Can Run Your Business  
**Date:** Tuesday 9 June 2026  
**Length:** 90 minutes  
**Presenter:** Harrison Living, HWL Studio

## Core Thesis

Content feels hard because every post starts from zero.

The answer is not more tools. The answer is a small content engine:

1. **Context:** the folder that explains the business, voice, rules, and formats.
2. **Cadence:** the rhythm that chooses one idea instead of chasing ten.
3. **Cascade:** the prompt that turns one idea into multiple useful drafts.
4. **Calendar:** the shipping layer that stops drafts dying in a folder.

The line to keep repeating:

> The AI is not the system. The context is.

## 0:00 to 0:08, Open And Set The Room

Slides: 1 to 2

Open with the problem:

Most founders treat content like a daily punishment. Wake up, stare at a blank page, ask ChatGPT for ideas, hate the output, post nothing.

Promise:

By the end, they will understand the shape of a simple content engine they can build for themselves.

Important expectation:

This is not a workshop about going viral. It is about making content easier to repeat without making it generic.

## 0:08 to 0:18, The Real Problem

Slide: 3

Frame:

Most founders do not have a content problem. They have a decision-load problem.

Three repeated decisions:

- What should I post?
- How should it sound?
- Where should it go?

Punchline:

If the same decisions come back every day, the system is broken.

## 0:18 to 0:30, The Reframe

Slides: 4 to 6

Main points:

- The tool is less important than the context.
- A chat box gives one-off answers.
- A system gives continuity.
- Good AI output needs instructions, source material, examples, constraints, and verification.

Use this line:

> If your AI output is bland, it probably has no idea who you are.

## 0:30 to 0:45, The Folder Tour

Slide: 7

Before sharing, pre-empt the terminal: "You do not need a terminal for this. This is just my tool. A folder of plain text files plus any chatbot you already pay for does the same job. Watch the shape, not the software." This keeps the system replicable for the non-technical half of the room.

Screen share the clean folder only.

Show four files:

- `content/strategy.md`
- `content/voice-dna.md`
- `content/publishing-rules.md`
- `content/waterfall.md`

Narrate each file as a decision removed:

- Strategy removes audience and positioning panic.
- Voice DNA removes generic AI cadence.
- Publishing rules remove risk and confidentiality issues.
- Waterfall removes format decisions.

Do not open:

- `capture/`
- `money/`
- `council/`
- `business/`
- client folders

## 0:45 to 1:05, Live Demo

Slides: 8 to 11

Set up the cadence:

One big idea per fortnight, not five fresh ideas a week.

Demo idea:

A film got 444,000 views. The next post reached almost nobody. The big number is vanity. The small number is the one that tells the truth.

Run the prompt from `demo-prompt-final.md`.

Tell them what to watch:

- Does it keep the voice?
- Does it keep the strategy?
- Does it create useful starts?

Important caveat:

Drafts are not finished posts. The engine removes the blank page. The founder still brings taste.

## 1:05 to 1:18, Make It Replicable

Slides: 12 to 14

Teach the build:

- Start with a strategy file.
- Add a voice file.
- Add a waterfall file.
- Add rules once the output starts creating risk.

Practical instruction:

Do not write documents. Answer decisions.

If a file does not remove a repeated decision, it is probably theatre.

## 1:18 to 1:25, Failure Modes

Slide: 15

Five ways it falls apart:

- Too many tools.
- No capture.
- No cadence.
- No editing taste.
- No calendar.

Strong line:

> The system only works if it closes loops.

## If The Live Demo Fails

Do not apologise for ten minutes.

Say:

> This is exactly why you need a system, not just a live magic trick. I ran the same prompt earlier, so let me show you the output and walk through what matters.

Then open `dry-run-1.md`, show the clean cascade, and narrate:

- The prompt read the context.
- The outputs held the same central thesis.
- Some lines are usable.
- Some lines still need human judgement.

That still proves the workshop.
