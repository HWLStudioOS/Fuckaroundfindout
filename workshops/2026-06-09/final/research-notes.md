# Research Notes

These are the external sources behind the workshop framing.

## Anthropic, Claude Code Product Page

Source: https://www.anthropic.com/product/claude-code

Useful support:

- Claude Code is framed as agentic, not autocomplete.
- It can read a codebase, understand directories, work across files, run tools, and iterate.
- The useful public framing for the workshop is that AI becomes stronger when it can work inside a project with real context.

## Anthropic, Claude Code Best Practices

Source: https://code.claude.com/docs/en/best-practices

Useful support:

- Context management is a core constraint.
- Give Claude ways to verify its work.
- Let Claude interview you for larger features.
- Use clear project context and reset context between unrelated tasks.

## OpenAI, Prompt Engineering Guide

Source: https://developers.openai.com/api/docs/guides/prompt-engineering

Useful support:

- Effective prompting relies on clear instructions and relevant context.
- Additional context can include proprietary data or selected reference material.
- Examples help steer model output.

## Practical Translation For The Workshop

Do not turn this into an academic section.

Say this instead:

> The tools are getting stronger. That does not mean your taste matters less. It means the quality of the context you give them matters more.
