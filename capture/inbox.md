# Capture Inbox

The one trusted intake. Codex H11: "Harrison's problem is not lack of tools, it is lack of one trusted intake."

Anything that's not yet sorted goes here. Tasks, ideas, learning notes, client obligations, voice memo transcripts, things to follow up on, things to ask Lich Fields, things to bring up with Maya. All start here.

## How items get in

- Harrison adds them directly during a session.
- `agents/discovery-scan.md` (Mon/Wed/Fri 14:00) appends auto-curated discoveries.
- `agents/morning-brief.md` references items from yesterday's intake.
- Voice memos transcribed (manual first, automated later) land here.

## How items get out

Weekly review (`agents/weekly-review.md` Sunday 18:00) processes the inbox into the right home:
- Tasks → either ship this week or get archived.
- Ideas → `content/pipeline.md` or `learning/recall-queue.md`.
- Client obligations → `business/clients/*.md` or `campaigns/*.md`.
- Money items → `money/index.md` or `money/inbox/`.
- Health items → `health/routines.md` or `health/training-plan.md` weekly notes.
- Relationship items → handled directly, optionally noted in `life/relationships.md`.

After processing, items either move or get a single-line "logged → action taken" entry and an archive marker.

## Format per item

```
## YYYY-MM-DD HH:MM
- {item}
- Source: {self / discovery / morning-brief / voice memo / etc.}
- Tag: {task / idea / client / money / health / relationship / learning / order / question}
- Status: {new / processing / actioned / archived}
```
