**Export (Route A, the one-click route):**

1. Select frame `435:2` > Export > PDF. The export preset on the frame already uses the document colour profile.
2. Size-check the file: `pdfinfo <file>.pdf | grep "Page size"`. The page must be **623.6 x 836.2 pt (220 x 295 mm)**. If Figma has written it at pixel-as-point size (2200 x 2950 pt) or anything else, run the resize step below.
3. Image-check: `pdfimages -list <file>.pdf`. The photograph should report at least 250 ppi at the final page size. If it is well under, use Route B.

Resize and box step (system Python has pypdf; run from anywhere, adjust the two paths):

```
/usr/bin/python3 - <<'EOF'
from pypdf import PdfReader, PdfWriter
from pypdf.generic import RectangleObject
src, dst = "IN.pdf", "Creepers_ProLandscaper_Sept2026_FullPage_220x295_bleed5.pdf"
W, H, INSET = 220*72/25.4, 295*72/25.4, 5*72/25.4
r = PdfReader(src); w = PdfWriter()
p = r.pages[0]
p.scale_to(W, H)
p.mediabox = RectangleObject([0, 0, W, H])
p.bleedbox = RectangleObject([0, 0, W, H])
p.trimbox = RectangleObject([INSET, INSET, W-INSET, H-INSET])
w.add_page(p); w.write(dst)
print("written", dst)
EOF
```

Then `pdfinfo` again to confirm 623.6 x 836.2 pt, and open it once at 100 percent to eyeball the QR and the small footer type.
