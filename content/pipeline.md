## Rules

- Every entry needs: idea, hook, format (long-form / LinkedIn post / X thread / video / newsletter), audience tag (B2B / personal / both), next action, next-action-by date.
- No more than 5 in "Drafting" at once. If hitting 5, finish one before starting the next.
- "Ready to post" items wait for one tap before going live.
- "Posted" entries include the link and the date posted. Weekly review tags performers vs duds.
