# Harrison OS

This workspace is the starting point for building a second brain and operating system for Harrison and HWL Studio.

## Root Files

- `../CLAUDE.md`: Claude Code handoff and operating instructions.
- `../README.md`: quick workspace start note.
- `../.gitignore`: protects local secrets, tokens, exports, and build output.

## Core Files

- `01-harrison-profile.md`: personal context, patterns, goals, and preferences.
- `02-business-map.md`: clients, offers, revenue, risks, and opportunities.
- `03-operating-theory.md`: current working hypotheses about how Harrison operates.
- `04-interview-log.md`: chronological source notes from interview rounds.
- `05-research-queue.md`: topics to research externally before turning ideas into strategy.
- `06-financial-snapshot.md`: current cash, debt, receivables, revenue, and finance risks.
- `07-relationship-map.md`: key personal and business relationships.
- `08-influences-and-voice.md`: creators, books, films, games, sports, and ideas that shaped Harrison.
- `09-health-performance.md`: health, training, recovery, and performance context.
- `10-finance-analysis-2026-05-11.md`: analysis of supplied statements and current money-control priorities.
- `11-attention-and-tools.md`: screen time, attention leaks, current tools, and capture systems.
- `12-command-center-spec.md`: first specification for the Harrison Command Center.
- `13-client-delivery-and-offers.md`: client workflows, delegation map, and flagship offer development.
- `14-sales-audience-positioning.md`: sales history, buyer language, audience direction, and positioning hypotheses.
- `15-psychology-and-standards.md`: motivation, shame triggers, standards, call-out rules, and grounding reminders.
- `16-relationships-home-environment.md`: Maya, family, New Zealand/London, and environment design.
- `17-learning-memory-taste.md`: learning goals, memory system needs, taste signals, and research brief shape.
- `18-system-requirements.md`: automation requirements, failure modes, check-ins, and product direction.
- `19-mvp-roadmap.md`: practical build sequence from Codex heartbeat to private phone app.
- `20-integrations-access-plan.md`: staged connector/MCP access plan and safety boundaries.
- `finance-inbox/`: place exported statements here for later analysis.

## Working Principle

The system should distinguish between:

- Facts Harrison has stated.
- Inferences Codex has made.
- Open questions that need verification.
- External research that should pressure-test the strategy.
